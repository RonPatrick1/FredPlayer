# Reviewer sample audio

`fredplayer-sample.flac` is a 12-second synthesized arpeggio created for
FredPlayer and first published by Silveron Studios. It contains no sampled
recording, third-party composition, or third-party performance. The identical
file is bundled in the Android and Apple targets so store reviewers can test
playback, metadata, leveling, and visualization without providing music.

Metadata:

- Title: FredPlayer Sample
- Artist: Silveron Studios
- Album: FredPlayer
